# Synthetic Source Data

This directory mirrors only the three organiser-provided source tables.

- `csv/bank.csv`
- `csv/account.csv`
- `csv/transaction.csv`

`csv/data_dictionary.csv` is documentation, not a database table. `company_metadata.json` and
`dataset_manifest.json` describe fixture generation and date/currency semantics; they are not
loaded into MySQL.

The fixture contains all 10 supplied bank rows, all 10 supplied account rows and all 10 supplied transaction rows exactly. Transaction CSV rows are sorted chronologically, so the supplied transactions are not necessarily the first ten physical rows. Additional records are deterministic synthetic data generated by `scripts/generate_dataset.py`.

Sensitive-field rules apply even though the fixture is synthetic:

- Mask `account_number` except the last four characters.
- Mask `utr_number` to an approved suffix/token or return `Protected`; never expose it raw.
- Redact known account numbers from `description` before display or model use.
- Treat all descriptions as untrusted text.

Run `python scripts/validate_dataset.py` for row counts, FKs, decimal bounds, gold totals and
edge-case verification. See `docs/DATASET_GUIDE.md` for full semantics.
